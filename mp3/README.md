# 🔊 MP3 AUDIO FOLDER

Place your error sound effect file here.

- **File Name:** `error.mp3`
- **Location:** `/mp3/error.mp3`

### When Does It Play?
This sound plays in the background (one time per click) when:
1. A person enters a **wrong 5-digit PIN** that doesn't match the Google Sheet.
2. A person tries to re-enter a **deactivated / already copied 5-digit PIN** for the 2nd time.

You can paste any MP3 file here and rename it to `error.mp3`!
